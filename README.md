# School Information & Student Registration Management System

A web-based school information and student registration management system that provides public school information and supports administrative management of student registration and website content.

## Overview

This project is a web-based school information system developed to provide centralized access to school information while supporting administrative activities related to student registration and content management.

The system combines a public-facing school website with administrative functionality for managing student data, school content, academic information, teachers, activities, achievements, gallery content, and other important information.

## Key Features

### Public Information

* School profile and information
* Academic program information
* Teacher and staff information
* Courses and extracurricular activities
* School activities and events
* Student achievements
* Gallery
* Important school information
* Contact information

### Student Registration

* Online student registration
* Student data submission
* Registration data management
* Student detail viewing
* Supporting document upload
* Registration data processing

### Administration

* Admin authentication
* Student data management
* Add, edit, and delete student records
* Teacher information management
* Gallery management
* Academic information management
* School service management
* Important information management
* Activity and achievement management
* Website content management
* Student data export

## System Workflow

```text
Visitor
   │
   ├── View School Information
   │
   └── Student Registration
             │
             ↓
      Submit Student Data
             │
             ↓
      Administrative Review
             │
             ↓
      Student Data Management
             │
             ↓
        Data Export
```
